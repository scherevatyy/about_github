📘 Шпаргалка по Git

Ключевые команды модуля.
Чтобы проще запомнить все команды, собрали их в одном месте 🚀

⸻

🔹 Инициализация репозитория

git init — initialize — инициализировать репозиторий.

⸻

🔹 Синхронизация локального и удалённого репозиториев

git remote add origin https://github.com/YandexPracticum/first-project.git — привяжи локальный репозиторий к удалённому.
git remote -v — verbose — проверь связь с удалённым.
git push -u origin main — push — загрузить изменения. Первый пуш с привязкой.

💡 Ваша ветка может называться master, а не main.

git push — загрузи коммиты в удалённый репозиторий.

⸻

🔹 Подготовка файла к коммиту

git add todo.txt — подготовь файл todo.txt к коммиту.
git add --all — подготовь к коммиту все изменённые и новые файлы.
git add . — добавь текущую папку и все файлы в ней.

⸻

🔹 Создание и публикация коммита

git commit -m "Комментарий к коммиту." — создай коммит с сообщением.
git push — отправь изменения в удалённый репозиторий.

⸻

🔹 Просмотр информации о коммитах

git log — подробная история коммитов.
git log --oneline — краткая история: хеш и сообщение.

⸻

🔹 Просмотр состояния файлов

git status — покажи текущее состояние репозитория.

⸻

🔹 Добавление изменений в последний коммит

git commit --amend --no-edit — добавь изменения в последний коммит без изменения сообщения.
git commit --amend -m "Новое сообщение" — измени сообщение последнего коммита.

💡 Выйти из редактора Vim: Esc → :qa! → Enter.

⸻

🔹 «Откат» файлов и коммитов

git restore --staged hello.txt — переведи файл hello.txt обратно в untracked/modified.
git restore hello.txt — верни файл hello.txt к последней сохранённой версии.
git reset --hard b576d89 — сбрось все незакоммиченные изменения до указанного коммита.

⸻

🔹 Просмотр изменений

git diff — покажи изменения в modified-файлах.
git diff a9928ab 11bada1 — сравни два коммита.
git diff --staged — покажи изменения, добавленные в staged.
